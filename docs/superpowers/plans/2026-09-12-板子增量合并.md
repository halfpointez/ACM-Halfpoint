```markdown
# MEX

> 所属分类: 基础算法 › MEX
> 复杂度: -

## 适用问题
- 求一个集合(或多重集合)中最小的没有出现过的非负整数

## 定义

MEX(Minimum EXcluded)是指一个集合(或多重集合)中最小的没有出现过的非负整数。

例如:

- MEX({0, 1, 3}) = 2, 因为 0、1 出现了, 2 没出现
- MEX({1, 2, 3}) = 0, 因为 0 没出现
- MEX(∅) = 0, 空集没有元素, 最小的非负整数 0 没出现
```
