# 练习计划：二分 / 三分 / 枚举 / 递归

我问什么就教什么，帮我理解清楚就行。

- 讲短一点：先给能用的做法，再讲为什么，别一口气铺太多。
- 代码我自己写，卡住再来问。

## 我卡的点（尺子、装修这两题暴露的）

- 二分：只会一套写法；mid 取整和 l/r 怎么配对、循环什么时候停，心里没底
- 三分：能看出是三分，写不出来
- 枚举：知道要暴力，但用哪个骨架、复杂度够不够，拿不准
- 递归：递归点在哪、什么顺序、什么时候撤销，模糊
- 对拍：不会，想要个最简单的，能验证自己写得对不对
