# 记忆化搜索

> 所属分类: 基础算法 › 搜索
> 复杂度: 状态数 × 单状态转移代价
> 备注: 2026-10-18 初稿, 待你核对

## 适用问题
- 有重叠子问题的搜索, 例: P1434 滑雪

## 模板 1: 二维网格

适用于在地图上向上下左右移动的场景。

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

int n, m;
int dx[4] = {0, 0, 1, -1};
int dy[4] = {1, -1, 0, 0};
int mp[105][105];
int memo[105][105]; // 初始化为 0，表示没算过（如果答案可能是0，则初始化为 -1）

bool in_bound(int x, int y) {
    return x >= 1 && x <= n && y >= 1 && y <= m;
}

// 核心 dfs：返回从 (x, y) 出发的最优答案
int dfs(int x, int y) {
    // 1. 记忆化查询（如果之前算过，直接拿来用）
    if (memo[x][y] != 0) return memo[x][y];

    // 2. 当前状态默认值（通常是 1，因为至少包含当前格子）
    int best = 1;

    // 3. 遍历所有邻居（这里是四个方向）
    for (int i = 0; i < 4; i++) {
        int nx = x + dx[i];
        int ny = y + dy[i];
        if (in_bound(nx, ny) && mp[nx][ny] < mp[x][y]) { // 按题目条件修改
            // 转移：一步代价(通常是 1) + 子问题的答案
            best = max(best, 1 + dfs(nx, ny));
            // 如果是求和：best += dfs(nx, ny);
            // 如果是求方案数：best += dfs(nx, ny);
        }
    }

    // 4. 保存结果到备忘录
    memo[x][y] = best;
    return best;
}
```

## 模板 2: 有向图(邻接表)

适用于任意有向图。

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

int n, m;
vector<vector<int>> graph; // 邻接表
vector<int> memo;          // 记忆化数组，初始化为 -1

// 核心 dfs：返回从节点 u 出发的最优答案
int dfs(int u) {
    // 1. 记忆化查询（如果之前算过，直接返回）
    if (memo[u] != -1) return memo[u];

    // 2. 当前状态默认值（默认为0，因为没有邻居时就走0步）
    int best = 0;

    // 3. 遍历所有后继节点 v
    for (int v : graph[u]) {
        // 转移：走一步(1) + v 的结果
        best = max(best, 1 + dfs(v));
        // 同样，如果是求方案数/和，换成相应的运算
    }

    // 4. 保存结果到备忘录
    memo[u] = best;
    return best;
}

int main() {
    // ... 读入 n, m, 建图 ...
    memo.assign(n + 1, -1); // 初始化为 -1 表示未计算

    // 遍历所有节点（图可能不连通）
    for (int i = 1; i <= n; i++) {
        dfs(i); // 只需要调用即可，答案会自动存入 memo
    }
    // 输出 memo[i] 就是每个点的答案
}
```
