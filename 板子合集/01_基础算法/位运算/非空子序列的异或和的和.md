# 非空子序列的异或和的和

> 所属分类: 基础算法 › 位运算
> 复杂度: O(n)

## 适用问题
- 求所有非空子序列异或和之和
- 结论: 答案 = 2^(n-1) × 所有数的按位或

这道题比子数组那题简单很多，关键结论是：

**所有非空子序列的异或和的总和 = \(2^{n-1} \times (\text{所有数的按位或})\)**

下面详细推导。

---

## 1. 按二进制位独立考虑

设数组长度为 \(n\)。对于二进制的第 \(b\) 位：

- 统计数组中第 \(b\) 位为 \(1\) 的元素个数，记为 \(c_1\)。
- 第 \(b\) 位为 \(0\) 的元素个数为 \(c_0 = n - c_1\)。

一个子序列的异或和在第 \(b\) 位为 \(1\)，当且仅当子序列中选了**奇数个**第 \(b\) 位为 \(1\) 的元素。  
第 \(b\) 位为 \(0\) 的元素选或不选，都不影响这一位的异或结果。

---

## 2. 统计第 \(b\) 位为 1 的子序列数量

- 从 \(c_1\) 个“1”元素中选奇数个的方案数：
  - 若 \(c_1 = 0\)，方案数为 \(0\)。
  - 若 \(c_1 > 0\)，选奇数个和选偶数个的方案数相等，各占一半。总方案数是 \(2^{c_1}\)，所以奇数个方案数为 \(2^{c_1 - 1}\)。
- 从 \(c_0\) 个“0”元素中任意选，方案数为 \(2^{c_0}\)。

因此，第 \(b\) 位为 1 的子序列数量为：

\[
\text{若 } c_1 > 0: \quad 2^{c_1 - 1} \times 2^{c_0} = 2^{c_1 + c_0 - 1} = 2^{n - 1}
\]

若 \(c_1 = 0\)，贡献为 \(0\)。

---

## 3. 总和的表达式

每一位 \(b\) 对总和的贡献是：

\[
(\text{该位为 1 的子序列数量}) \times 2^b
\]

如果数组中至少有一个元素在第 \(b\) 位为 \(1\)（即 \(c_1 > 0\)），那么贡献就是：

\[
2^{n-1} \times 2^b
\]

把所有这样的位加起来，正好是：

\[
2^{n-1} \times \left( \sum_{b: \text{存在元素第 } b \text{ 位为 } 1} 2^b \right)
\]

而括号里的部分，正是所有元素的**按位或**（OR）的值。

所以答案就是：

\[
\text{ans} = 2^{n-1} \times (\text{所有数的按位或}) \pmod{10^9+7}
\]

---

## 4. 验证样例

样例：`a = [1, 2, 3]`

- 按位或：`1 | 2 | 3 = 3`
- \(n = 3\)，\(2^{n-1} = 2^2 = 4\)
- 答案：\(4 \times 3 = 12\)，与题目输出一致。

样例：`a = [3, 5]`

- 按位或：`3 | 5 = 7`
- \(n = 2\)，\(2^{n-1} = 2\)
- 答案：\(2 \times 7 = 14\)，与之前子数组的样例一致（巧合，但正确）。

---

## 5. 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const long long MOD = 1e9 + 7;

long long qpow(long long a, long long b) {
    long long res = 1;
    while (b) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    long long or_val = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        or_val |= x;
    }

    long long ans = qpow(2, n - 1) * (or_val % MOD) % MOD;
    cout << ans << '\n';

    return 0;
}
```

---

## 6. 复杂度分析

- 时间复杂度：\(O(n + \log n)\)，主要是读入和快速幂。
- 空间复杂度：\(O(1)\)，不需要存储整个数组。

对于 \(n \le 2 \times 10^5\)，完全没问题。

---

## 7. 注意事项

- 模数是 \(10^9+7\)。
- \(2^{n-1}\) 用快速幂计算，注意 \(n=1\) 时 \(2^0=1\)。
- 按位或的结果可能很大（最大 \(10^9\) 左右），取模后再乘。
- 输入元素可能为 0，不影响按位或。

这样就能轻松通过。
