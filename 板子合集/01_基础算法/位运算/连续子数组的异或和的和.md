# 连续子数组的异或和的和

> 所属分类: 基础算法 › 位运算
> 复杂度: O(n log A)

## 适用问题
- 求所有连续子数组异或和之和
- 对应题目: U360489 灵茶八题 - 子数组 ^w+

典题

## 题目描述

给你一个长为 $n$ 的数组 $a$，输出它的所有连续子数组的异或和的和。

例如 $a=[3,5]$ 有三个连续子数组 $[3],[5],[3,5]$，异或和分别为 $3,5,6$，所以答案为 $3+5+6=14$。

## 输入格式

第一行输入一个整数 $n\ (1\le n \le 10^5)$。

第二行输入 $n$ 个非负整数，表示数组 $a$ 中的元素 $(0\le a[i] \le 10^6)$。

## 输出格式

一个整数，表示 $a$ 的所有连续子数组的异或和的和。

## 输入输出样例 #1

### 输入 #1

```
2
3 5
```

### 输出 #1

```
14
```

## 输入输出样例 #2

### 输入 #2

```
1
1
```

### 输出 #2

```
1
```

这是一道非常典的题目 很有可能能用上

对于子数组以及^ | & 的题目 我们通常考虑贡献法及位运算

## 思路

对于子数组与 `^`、`|`、`&` 的题目, 通常考虑**贡献法 + 位运算**。

把整数按二进制拆开: X = Σ_b (X 的第 b 位) × 2^b。

所有子数组异或和的总和 = Σ_b 2^b × (异或和第 b 位为 1 的子数组个数)。

对固定的第 b 位: 子数组 [l, r] 的异或和 = pre[r] ⊕ pre[l-1], 其第 b 位为 1 当且仅当 pre[r] 与 pre[l-1] 的第 b 位**不同**。

统计 pre[0..n] 中第 b 位为 0 的个数 cnt0、为 1 的个数 cnt1(cnt0 + cnt1 = n + 1), 则这一位的贡献 = cnt0 × cnt1 × 2^b。

代码如下

```cpp
#include <bits/stdc++.h>
using namespace std;
#define endl '\n'
using i64 = long long;

i64 ksm(i64 a,i64 b) {
	i64 res = 1;
	while (b) {
		if(b & 1LL) res *= a;
		a *= a;
		b >>= 1LL;
	}
	return res;
}

int main() {
	i64 n;
	cin >> n;
	vector<i64> a(n + 1);
	vector<i64> pre(n + 1);
	pre[0] = 0;
	a[0] = 0;
	for(int i = 1; i <= n; i++) {
		cin >> a[i];
		pre[i] = a[i] ^ pre[i - 1];
	}
	vector<i64> cnt0(32, 0), cnt1(32, 0);

	for(int i = 0; i <= n; i++) {
		i64 cnt = 0;
		while (cnt <= 31) {
			if(pre[i] & (1LL << cnt)) cnt1[cnt]++;
			else cnt0[cnt]++;
			cnt++;
		}
	}
	i64 ans = 0;
	for(int i = 0; i <= 31; i++) {
		ans += cnt0[i] * cnt1[i] * ksm(2, i);
	}
	cout << ans << endl;

	

}
```
