# 无向图找环

> 所属分类: 图论 › 环问题
> 复杂度: O(V + E)(并查集版 O(E α(V)))

## 适用问题
- 判断无向图是否有环
- 输出环上的节点路径(DFS 版)
- 只需判断时用并查集最快(不能输出路径)

下面三个板子都按照你的代码风格来写：`bits/stdc++.h`、`using i64`、`#define endl`、从 `1` 开始编号、函数传引用、用 `vector` 存图。每个板子都能返回“是否存在结点数 ≥ 3 的环”，并尽可能给出环上的节点。

---

## 一、DFS 找环（推荐，能直接输出环路径）

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;
#define endl '\n'

vector<vector<int>> Node;
vector<int> parent_;
vector<int> cycle;
vector<int> vis;
bool found = false;

void dfs(int u, int p) {
    vis[u] = 1;
    parent_[u] = p;
    for(auto &v : Node[u]) {
        if(found) return;
        if(v == p) continue;
        if(vis[v]) {
            // 找到环，从 u 回溯到 v
            found = true;
            cycle.push_back(v);
            int cur = u;
            while(cur != v) {
                cycle.push_back(cur);
                cur = parent_[cur];
            }
            cycle.push_back(v);
            return;
        }
        if(!vis[v]) {
            dfs(v, u);
            if(found) return;
        }
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    Node.assign(n + 1, {});
    vis.assign(n + 1, 0);
    parent_.assign(n + 1, -1);
    for(int i = 1; i <= m; i++) {
        int u, v;
        cin >> u >> v;
        if(u == v) continue;   // 忽略自环
        Node[u].push_back(v);
        Node[v].push_back(u);
    }
    for(int i = 1; i <= n; i++) {
        if(!vis[i]) {
            dfs(i, -1);
            if(found) break;
        }
    }
    if(!found) {
        cout << "无环" << endl;
    } else {
        cout << "有环：";
        for(auto &x : cycle) cout << x << " ";
        cout << endl;
    }
}
```

**说明**：
- `parent_[u]` 记录 DFS 树上的父节点；
- 遇到 `vis[v] && v != p` 就是回边，说明有环；
- 从 `u` 沿着 `parent_` 回溯到 `v`，路径就是环。

**复杂度**：`O(V + E)`

## 二、BFS 找环（能判断，路径略麻烦）

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;
#define endl '\n'

vector<vector<int>> Node;
vector<int> parent_;
vector<int> vis;

bool bfs_check(int start) {
    queue<int> q;
    q.push(start);
    vis[start] = 1;
    parent_[start] = -1;
    while(!q.empty()) {
        int u = q.front();
        q.pop();
        for(auto &v : Node[u]) {
            if(!vis[v]) {
                vis[v] = 1;
                parent_[v] = u;
                q.push(v);
            } else if(v != parent_[u]) {
                return true;   // 有环
            }
        }
    }
    return false;
}

int main() {
    int n, m;
    cin >> n >> m;
    Node.assign(n + 1, {});
    vis.assign(n + 1, 0);
    parent_.assign(n + 1, -1);
    for(int i = 1; i <= m; i++) {
        int u, v;
        cin >> u >> v;
        if(u == v) continue;   // 忽略自环
        Node[u].push_back(v);
        Node[v].push_back(u);
    }
    bool found = false;
    for(int i = 1; i <= n; i++) {
        if(!vis[i]) {
            if(bfs_check(i)) {
                found = true;
                break;
            }
        }
    }
    if(found) cout << "有环" << endl;
    else cout << "无环" << endl;
}
```

**说明**：
- BFS 在无向简单图中遇到 `vis[v] && v != parent_[u]` 就说明有环；
- 想输出环路径的话，需要额外从 `u` 和 `v` 同时向上回溯到 LCA，比 DFS 麻烦，一般检测用 BFS，输出环用 DFS。

**复杂度**：`O(V + E)`

## 三、并查集找环（最简单，但不能输出环路径）

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;
#define endl '\n'

vector<int> fa;

int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

bool merge(int u, int v) {
    int ru = find(u), rv = find(v);
    if(ru == rv) return false;  // 已经连通，再加边就有环
    fa[ru] = rv;
    return true;
}

int main() {
    int n, m;
    cin >> n >> m;
    fa.resize(n + 1);
    for(int i = 1; i <= n; i++) fa[i] = i;

    bool found = false;
    for(int i = 1; i <= m; i++) {
        int u, v;
        cin >> u >> v;
        if(u == v) continue;   // 忽略自环
        if(!merge(u, v)) {
            found = true;
            break;
        }
    }
    if(found) cout << "有环" << endl;
    else cout << "无环" << endl;
}
```

**说明**：
- 遍历每条边，如果两端已经属于同一集合，说明加入这条边会形成环；
- 简单无向图中，这样找到的环长度一定 ≥ 3（自环已忽略，重边需额外去重）；
- 不能给出环上的具体节点，只能判断有没有环。

**复杂度**：`O(E · α(V))`，近似 `O(E)`

---

## 三个板子的对比

| 方法   | 能否判断 | 能否输出环路径   | 复杂度      | 适用场景                 |
| ------ | -------- | ---------------- | ----------- | ------------------------ |
| DFS    | 能       | 能，回溯即可     | `O(V+E)`    | 需要具体环，最常用       |
| BFS    | 能       | 麻烦，需要找 LCA | `O(V+E)`    | 只需要判断，或者求最短环 |
| 并查集 | 能       | 不能             | `O(E α(V))` | 只需要判断，代码最短     |

---

## 注意事项

1. **自环**：`u == v` 是长度 1 的环，题目要求 ≥ 3，所以读入时直接跳过。
2. **重边**：`u - v` 有两条边会形成长度 2 的环，也不满足 ≥ 3，需要去重。  
   如果题目可能有重边，可以在读入时用 `set<pair<int,int>>` 去重，或者只保留一条。
3. **非连通图**：需要遍历所有未访问的点，确保每个连通分量都检查过。
4. **多个环**：以上代码找到第一个环就返回。如果需要找所有环，要用 Tarjan 求点双 / 边双，或者 DFS 枚举。

选择建议：

> **要判断有没有环，用并查集最快最简洁；要输出环上的节点，用 DFS；BFS 适合只需要判断或求最短环的场景。**
