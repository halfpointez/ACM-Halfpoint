# 拓扑排序

> 所属分类: 图论 › 环问题 | 图论 › 为DP提供计算顺序
> 复杂度: O(n + m)

## 适用问题
- 有向无环图(DAG): 得到点的先后顺序, 供线性DP/树形DP等需要前置顺序的算法使用
- 有环图: 拓扑排序后剩下的不在答案数组中的就是环上的节点
- 判环: 答案长度 < n 说明有环

## 说明
拓扑排序 
1.对于有向无环图 得到点的先后顺序 得到先后顺序后 可以在dp之类需要前置顺序的算法中使用
2.对于有环图 进行拓扑排序后 剩下的不在答案数组中的就是 环上的节点
时间复杂度为O(n)

## 完整模板
```cpp
	#include <bits/stdc++.h>
	using namespace std;
	using i64 = long long;
	#define endl '\n'

	vector<i64> topo_sort(vector<i64> &In_Deg, vector<vector<i64>>	&Node, queue<i64> &q) {
		i64 n = Node.size() - 1;
		vector<i64> ans;
		for(int i = 1; i <= n; i++) {
			if(In_Deg[i] == 0) q.push(i);
		}
		while (!q.empty()) {
			i64 cur = q.front();
			q.pop();
			ans.push_back(cur);
			for(auto &i:Node[cur]) {
				In_Deg[i]--;
				if(In_Deg[i] == 0) {
					q.push(i);
				}
			}
		}
		return ans;
	}

	int main() {
		int n;
		cin >> n;
		vector<i64> ans;
		vector<i64> In_Deg(n + 1); //记录每个节点的入度
		vector<vector<i64>>	Node(n + 1); //记录每个节点的出度
		queue<i64> q; //当前入度为0的节点
		for(int i = 1; i <= n; i++) {
			while (1) {
				int cur;
				cin >> cur;
				if(cur == 0) break;
				Node[i].push_back(cur);
				In_Deg[cur]++;
			}
		}
		ans = topo_sort(In_Deg, Node, q);
		for(auto &i:ans) cout << i << ' ';
		
	}
```
