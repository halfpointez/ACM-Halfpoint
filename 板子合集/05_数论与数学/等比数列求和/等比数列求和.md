# 等比数列求和

> 所属分类: 数论与数学 › 等比数列求和
> 复杂度: O(1)(公式)或 O(log n)(结合快速幂)

## 适用问题
- 等比数列前 n 项和、无穷等比级数(|q|<1)

## 6.2 等比数列求和公式笔记
### 1. 基本公式
设等比数列首项为 $a_1$，公比为 $q$，项数为 $n$。

当 $q \neq 1$ 时：
$$S_n = \frac{a_1(1-q^n)}{1-q}$$

当 $q = 1$ 时：
$$S_n = na_1$$

### 2. 公式推导（错位相减法）
$$
\begin{aligned}
S_n &= a_1 + a_1q + a_1q^2 + \cdots + a_1q^{n-1} \\
qS_n &= \quad\;\; a_1q + a_1q^2 + \cdots + a_1q^{n-1} + a_1q^n
\end{aligned}
$$

两式相减：
$$S_n - qS_n = a_1 - a_1q^n$$
$$(1-q)S_n = a_1(1-q^n)$$
$$\therefore S_n = \frac{a_1(1-q^n)}{1-q}$$

### 3. 无穷等比数列（|q|<1）
$$S = \frac{a_1}{1-q}$$

### 4. 常用变形
| 已知条件          | 公式                            |
| ----------------- | ------------------------------- |
| 已知 $a_1$、$a_n$ | $S_n = \frac{a_1 - a_n q}{1-q}$ |
| 已知 $a_1$、$a_n$ | $S_n = \frac{a_n q - a_1}{q-1}$ |

其中 $a_n = a_1 q^{n-1}$。
