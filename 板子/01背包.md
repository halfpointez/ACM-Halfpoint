# 01 背包板子合集

## 板子 0：基础模型

- 有 `n` 个物品，背包容量 `C`
- 第 `i` 个物品：重量 `w[i]`，价值 `v[i]`
- 每个物品最多选 1 次

所有变式都基于这个模型，区别只在**问法**和**初始化**。

---

## 板子 1：最大价值（容量不超过 C）

**适用**：P1048 采药、P1060 开心的金明

**状态**：
```text
dp[j] = 容量不超过 j 时，能获得的最大价值
```

**初始化**：
```cpp
vector<int> dp(C + 1, 0);
```

**转移**：
```cpp
dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

**循环**：
```cpp
for (int i = 1; i <= n; i++) {
    for (int j = C; j >= w[i]; j--) {   // 倒序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

**答案**：
```cpp
dp[C]
```

**模板**：
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, C;
    cin >> n >> C;
    vector<int> w(n + 1), v(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];

    vector<int> dp(C + 1, 0);
    for (int i = 1; i <= n; i++)
        for (int j = C; j >= w[i]; j--)
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

    cout << dp[C] << endl;
    return 0;
}
```

## 板子 2：恰好装满的最大价值

**适用**：牛客模板 01 背包（恰好装满部分）

**状态**：
```text
dp[j] = 容量恰好为 j 时，能获得的最大价值
```

**初始化**：
```cpp
vector<int> dp(C + 1, -1e9);  // 负无穷表示不可达
dp[0] = 0;                    // 容量 0 恰好装满，价值 0
```

**转移**：
```cpp
dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

**循环**：
```cpp
for (int i = 1; i <= n; i++) {
    for (int j = C; j >= w[i]; j--) {   // 倒序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

**答案**：
```cpp
dp[C]  // 若仍为 -1e9，说明无法恰好装满
```

**模板**：
```cpp
vector<int> dp(C + 1, -1e9);
dp[0] = 0;
for (int i = 1; i <= n; i++)
    for (int j = C; j >= w[i]; j--)
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

cout << dp[C] << endl;
```

## 板子 3：可行性（能否恰好装满 / 能否达到某容量）

**适用**：P1049 装箱问题、LeetCode 416 分割等和子集

**状态**：
```text
dp[j] = 容量 j 能否恰好被装满（bool）
```

**初始化**：
```cpp
vector<bool> dp(C + 1, false);
dp[0] = true;   // 容量 0 总是可达
```

**转移**：
```cpp
if (dp[j - w[i]]) dp[j] = true;
```

**循环**：
```cpp
for (int i = 1; i <= n; i++) {
    for (int j = C; j >= w[i]; j--) {   // 倒序
        if (dp[j - w[i]]) dp[j] = true;
    }
}
```

**答案**：
- 能否恰好装满 `C`：`dp[C]`
- 最大可达容量：从 `C` 向下找第一个 `dp[j] == true` 的 `j`

**模板（P1049 装箱问题）**：
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int V, n;
    cin >> V >> n;
    vector<int> v(n + 1);
    for (int i = 1; i <= n; i++) cin >> v[i];

    vector<bool> dp(V + 1, false);
    dp[0] = true;
    for (int i = 1; i <= n; i++)
        for (int j = V; j >= v[i]; j--)
            if (dp[j - v[i]]) dp[j] = true;

    int ans = V;
    for (int j = V; j >= 0; j--) {
        if (dp[j]) { ans = V - j; break; }
    }
    cout << ans << endl;
    return 0;
}
```

## 板子 4：方案数（恰好装满）

**适用**：P1164 小A点菜

**状态**：
```text
dp[j] = 恰好装满容量 j 的方案数
```

**初始化**：
```cpp
vector<int> dp(C + 1, 0);
dp[0] = 1;   // 容量 0 有 1 种方案：什么都不选
```

**转移**：
```cpp
dp[j] += dp[j - w[i]];
```

**循环**：
```cpp
for (int i = 1; i <= n; i++) {
    for (int j = C; j >= w[i]; j--) {   // 倒序
        dp[j] += dp[j - w[i]];
    }
}
```

**答案**：
```cpp
dp[C]
```

**模板（P1164）**：
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];

    vector<int> dp(m + 1, 0);
    dp[0] = 1;
    for (int i = 1; i <= n; i++)
        for (int j = m; j >= a[i]; j--)
            dp[j] += dp[j - a[i]];

    cout << dp[m] << endl;
    return 0;
}
```

## 板子 5：最大价值的方案数（容量不超过）

**适用**：AcWing 11 / 洛谷 U224067

**状态**：
```text
dp[j]  = 容量不超过 j 时的最大价值
cnt[j] = 达到最大价值的方案数
```

**初始化**：
```cpp
vector<int> dp(C + 1, 0);
vector<int> cnt(C + 1, 1);   // 什么都不选，价值 0，方案数 1
```

**转移**：
```cpp
int take = dp[j - w[i]] + v[i];
int not_take = dp[j];

if (take > not_take) {
    dp[j] = take;
    cnt[j] = cnt[j - w[i]];
} else if (take == not_take) {
    cnt[j] = (cnt[j] + cnt[j - w[i]]) % MOD;
}
```

**循环**：
```cpp
for (int i = 1; i <= n; i++) {
    for (int j = C; j >= w[i]; j--) {   // 倒序
        // 上述转移
    }
}
```

**答案**：
```cpp
cnt[C]
```

**模板**：
```cpp
const int MOD = 1e9 + 7;
vector<int> dp(C + 1, 0);
vector<int> cnt(C + 1, 1);

for (int i = 1; i <= n; i++) {
    for (int j = C; j >= w[i]; j--) {
        int take = dp[j - w[i]] + v[i];
        int not_take = dp[j];
        if (take > not_take) {
            dp[j] = take;
            cnt[j] = cnt[j - w[i]];
        } else if (take == not_take) {
            cnt[j] = (cnt[j] + cnt[j - w[i]]) % MOD;
        }
    }
}
cout << cnt[C] << endl;
```

## 板子 6：输出具体方案（字典序最小）

**适用**：AcWing 12 / 洛谷 U224072

**特点**：需要保留每一层状态，必须用**二维 DP**，且从后往前做 DP，从前往后倒推。

**状态**：
```text
dp[i][j] = 从第 i 个物品到第 N 个物品，容量不超过 j 的最大价值
```

**初始化**：
```cpp
vector<vector<int>> dp(N + 2, vector<int>(V + 1, 0));
```

**转移（从后往前）**：
```cpp
for (int i = N; i >= 1; i--) {
    for (int j = 0; j <= V; j++) {
        dp[i][j] = dp[i + 1][j];              // 不选
        if (j >= v[i]) {
            dp[i][j] = max(dp[i][j], dp[i + 1][j - v[i]] + w[i]);  // 选
        }
    }
}
```

**倒推方案（从前往后，能选就选）**：
```cpp
int bag = V;
for (int i = 1; i <= N; i++) {
    if (bag >= v[i] && dp[i][bag] == dp[i + 1][bag - v[i]] + w[i]) {
        cout << i << " ";
        bag -= v[i];
    }
}
```

**完整模板**：
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, V;
    cin >> N >> V;
    vector<int> v(N + 2), w(N + 2);
    for (int i = 1; i <= N; i++) cin >> v[i] >> w[i];

    vector<vector<int>> dp(N + 2, vector<int>(V + 1, 0));
    for (int i = N; i >= 1; i--) {
        for (int j = 0; j <= V; j++) {
            dp[i][j] = dp[i + 1][j];
            if (j >= v[i])
                dp[i][j] = max(dp[i][j], dp[i + 1][j - v[i]] + w[i]);
        }
    }

    int bag = V;
    for (int i = 1; i <= N; i++) {
        if (bag >= v[i] && dp[i][bag] == dp[i + 1][bag - v[i]] + w[i]) {
            cout << i << " ";
            bag -= v[i];
        }
    }
    cout << endl;
    return 0;
}
```

## 通用易错点

1. **一维 01 背包内层必须倒序**：`j` 从 `C` 到 `w[i]`。
2. **二维转移选物品时用 `dp[i-1]`**，不是 `dp[i]`。
3. **恰好装满**：初始化 `dp[0]=0`，其余 `-inf`。
4. **方案数（恰好）**：初始化 `dp[0]=1`，其余 `0`。
5. **最大价值方案数**：`cnt` 初始全为 `1`。
6. **输出具体方案**：必须二维，从后往前 DP，从前往后倒推。
7. **完全背包内层正序**：`for (int j = w[i]; j <= C; j++)`。
